# 资讯与案例

巡查：2026-11-05。收 AI 教育相关的政策动态、商业案例、产品使用案例和观点文章。它们不进产品索引，但能说明产品在什么场景被用、被管、被卖。

只写事实摘要：谁、何时、做了什么、涉及哪些产品、用在什么场景。原文里的评价、夸张说法和营销话术不搬过来；观点类只写「文章主张……」，不替它下结论。

## 收录规则

1. 与 AI + 教育 / 学习直接相关：政策、市场、机构或个人的真实做法、产品使用记录、有论点的文章。
2. 能落成一个可产品化的产品或 Skill 的，先按 README「收录标准」进 `product/` 或 `skills/`，这里不重复。
3. 商业案例和产品案例必须写「涉及产品」和「应用场景」；原文没点名的写「原文未点名（未核）」，不要猜。
4. 去掉主观评价和营销词：「大生意」「太牛」「封神」「降维打击」这类不写；收入、人数等数字只写原文说法并标注出处，没核到的标「未核」。
5. 来源优先链原始出处（官方文件、原帖、原文）；找不到原始出处时链得到笔记，并标「原始出处未核」。
6. 同一事件多条笔记合并成一条，来源都列上。
7. 每个小节内按日期倒序（新的在上）。

## 政策动态

### 北京发布《北京市教育领域人工智能应用指南（2026 年）》，多地出台 AI 教育政策

- 类型：政策
- 日期：2026-09-24（北京教育科学研究院发布页日期）
- 来源：[指南发布页](https://www.bjesr.cn/xskw/nbck1/) · [指南 PDF](https://www.bjesr.cn/d/file/xskw/nbck1/2026zn/2026-09-24/2feb7fff902d0633a08d69ffd57ab012.pdf) · [北京日报报道](https://xinwen.bjd.com.cn/content/s6abb9061e4b0e42f8f00fc31.html) · [得到笔记](https://www.biji.com/note/1923754853403496648)
- 核查：北京部分已核原文；浙江、黑龙江部分未核

- 指南采用「1+5+2」结构（总指南 + 基础 / 高等 / 职业 / 终身 / 特殊教育五个导引 + 通识教育与伦理安全两个专题），并设「禁止准入」「有限使用」「鼓励使用」三类清单。
- 禁止准入示例：学生须独立完成的作业、测评、考试不得由 AI 代写代做；不得以 AI 替代教师课堂主导和即时专业判断；不得把 AI 评分作为成绩认定的唯一依据。
- 教师侧应用场景包括教学设计、学情分析、课件与资源制作，要求教师对 AI 输出做事实核查和价值观审查。
- 分学段：0–3 岁不建议直接接触 AI 工具；3–6 岁可在家长陪伴下有限体验；小学不建议学生独自使用；初中可在教师或家长陪伴下适度探索；高中可在教师许可下开展探究性学习。
- 笔记称浙江、黑龙江等地也陆续出台相关政策，具体文件未核。
