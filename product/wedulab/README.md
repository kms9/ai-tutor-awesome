# WeduLab

- 形态：免费 Web 教具合集（浏览器即开，免安装、免注册）
- 作者：Teacher WY（X [@akokoi1](https://x.com/akokoi1)）
- 链接：[官网](https://wedulab.com)
- 状态：相邻对照

## 简介

面向初高中课堂的三维 / 动画交互实验合集，按学科、学段、知识点标注，打开就能投屏讲或发给学生自己拖。例子：等高线水平面切割 + 剖面图 + 随堂检测、写实显微镜 26 种玻片、孟德尔豌豆杂交后卡方检验 3:1、尺规作图闯关评星。实验是作者用 Claude 做好的成品，课堂上不跑 AI，也不吃老师的课件。放进清单是作为「AI 做课的产出长什么样」的对照，和 AetherViz Master 这类生成 Skill 对着看。

## 建议使用场景

适合：

- 讲三维 / 动态的抽象知识点：三圈环流、晨昏线、电子云、细胞结构、圆锥曲线。
- 课堂投屏演示，或把链接发班级群让学生自主探究。
- 用随堂检测、闯关评星当课后探究任务。
- 自己用 AI 做教具前，先看一个成熟样板的交互密度和学科标注方式。

不适合：

- 要把自己的讲义 / PDF 变成课（去 OpenMAIC / DeepTutor / Hyperknow）。
- 要按需生成新主题的教具（用 [AetherViz Master](../../skills/education-community.md)、作者的 edulab 之类 Skill 自己生成，或用 [懂了鸭](../dongleya/README.md) 在线生成）。
- 要 AI 家教、追问、掌握度记录。
- 要题库、作业批改或考试刷题。

## Skill

无公开 `SKILL.md`，也没有产品内 AI。每个实验是固定网页：

| 产品流程 | 动作 | 对应维度 |
|---|---|---|
| 3D / 动画演示 + 可调参数 | 教 | 视觉知识结构 |
| 随堂检测、闯关评星（部分实验） | 练 | 解题/出题（弱） |
| 学科 / 学段 / 知识点标注 | 备 | — |

作者另开源了教育 Skill 集 [wy51ai/edulab](https://github.com/wy51ai/edulab)（Apache-2.0，作者署名 WY · @akokoi1）：把一道题做成交互教学网页（立体几何、解析几何、化学反应微观演示）或带配音的讲解视频（数学、物理、化学）。edulab README 没有说明它与 wedulab.com 上这些实验的关系（未核）。条目见 [skills/education-community.md](../../skills/education-community.md)。

总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)。
