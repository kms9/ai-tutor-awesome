# Learn Your Way

- 形态：Google Research / Google Labs 研究实验（Web），基于 LearnLM / Gemini 2.5 Pro
- 链接：[官网](https://learnyourway.withgoogle.com/) · [Google Research 发布帖](https://research.google/blog/learn-your-way-reimagining-textbooks-with-generative-ai/) · [技术报告 arXiv 2509.13348](https://arxiv.org/abs/2509.13348)
- 状态：观察

## 简介

把教材 PDF 改写成按年级和兴趣个性化的互动课。学习者先选年级和兴趣（如运动、音乐、食物），系统把原文改写到对应年级、把通用例子换成兴趣相关的例子，再以这份改写稿为底生成五种形态：分节的沉浸式文本（配生成插图和嵌入问题）、分节测验、幻灯片与旁白、AI 老师与 AI 学生对话的音频课、思维导图。测验结果会提示回看没掌握的段落。它是研究实验，官网目前开放的是 Google 预先生成的示例课；普通用户能否上传自有 PDF 未核。

## 建议使用场景

适合：

- 对照「同一份教材 → 多种表征 + 个性化例子」的做法，设计自己的成课流程。
- 看分节测验怎么回指原文段落，作为「练 → 回看」闭环的参考。
- 中学生用官方示例课体验同一内容的文本、幻灯片、音频、导图几种读法。

不适合：

- 要稳定地把自己的讲义变成课（自有 PDF 上传是否对公众开放未核；去 OpenMAIC / DeepTutor / Hyperknow）。
- 要跨会话记忆、长期学习计划。
- 要可安装 `SKILL.md`、自托管或换模型。
- 中文教材（官方示例与评测材料为英文 OpenStax 教材；中文效果未核）。

## Skill

无公开 `SKILL.md`。流程锁在产品内：

| 产品流程 | 动作 | 对应维度 |
|---|---|---|
| 选年级 + 兴趣 → 改写原文、替换例子 | 备 | 资料摄入、一键成课 |
| 沉浸式文本（插图 + 嵌入问题） | 教 | 一键成课、视觉知识结构 |
| 分节测验 + 反馈回看 | 练 / 评 | 解题/出题 |
| 幻灯片与旁白、音频课（AI 师生对话） | 教 | 一键成课 |
| 思维导图 | 教 | 视觉知识结构 |

总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)。

## 能力对照

| 维度 | 本产品 |
|---|---|
| 资料摄入 | 中：设计输入为教材 PDF（前端代码有 PDF 上传流程）；公众可用的上传入口未核 |
| 一键成课 | 强：同一份改写稿生成沉浸式文本、幻灯片与旁白、音频课 |
| 直播课堂 | —（音频课是预生成的师生对话，不是实时课堂） |
| 解题/出题 | 中：分节测验，有反馈与学习状态分级 |
| 主动规划 | 弱：按测验结果提示回看段落 |
| 长期记忆 | 未核 |
| 视觉知识结构 | 中：生成教育插图、思维导图、时间线（研究帖提及） |
| 可复用 Skill | 无 |
| 自托管 / 换模型 | 否 |
| 导出 | 未核 |

相对锚点：成课形态接近 OpenMAIC 的「资料进、整课出」，但不是实时演课；个性化改写是四锚点都没有单独做的一层；测验和记忆弱于 DeepTutor / Hyperknow；没有 Heptabase 式的用户知识库。
