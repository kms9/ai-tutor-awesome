- 形态：腾讯青少儿 AI 互动内容社区（Web；微信小程序名「懂了鸭AhaDuck」未核），内测中，需邀请码
- 出品：腾讯 PCG（媒体报道，未见腾讯官方公告，未核）
- 链接：[官网](https://dongleya.qq.com/) · [官方创作 Skill 包 v2.2.1](https://dongleya.qq.com/d_file/skills/dly-ca-skill-2.2.1.zip)
- 状态：相邻对照
- 收录说明：边界产品。按 README 收录标准，只确定满足第 2 条（产出互动课件、3D 演示、记忆卡）；第 1 条只到「输入主题或粘贴材料」，不吃 PDF；第 3 条弱，是内容加社区，没有讲解、追问、练习闭环。与 [WeduLab](../wedulab/README.md) 同属「互动教具」一类，区别是它由用户用 AI 生成并发布到社区，故放在相邻对照。

## 简介

面向学前到高中的 AI 互动内容社区。官网描述：帮助家长、教师和知识创作者发现内容，并借助 AI 创作、改编和分享「玩一玩」、动画、绘本与互动课件。创作端输入一个主题或粘贴一段材料，选择作品类型（官网前端可见：动画、绘本、动态课件、3D 演示、记忆卡、互动课件），由 Agent 生成单个可交互 HTML 作品，可选择引用「知识树」（按国家中小学智慧教育平台电子教材整理到册级、并对应国家课程标准）。作品发布到社区后可被浏览和改编。另有官方 Skill 包，让外部 Agent（Skill 文中点名 Codex、Cursor、WorkBuddy）在本地做好 HTML 后用个人令牌上传为投稿副本，由用户本人在网页上发布。

## 建议使用场景

适合：

- 家长或教师把一个知识点做成可拖、可调参数的互动页，课堂投屏或亲子共用。
- 先在社区找现成作品，再改编成自己的版本。
- 在 Codex / Cursor / WorkBuddy 等外部 Agent 里做 HTML 教具，再用官方 Skill 投到懂了鸭。
- 和 WeduLab（作者手做的成品实验）、AetherViz Master（本地生成 Skill）对照：同类产出，三种生产方式。

不适合：

- 要把自己的讲义 / PDF 变成整课（去 OpenMAIC / DeepTutor / Hyperknow）。
- 要 AI 家教、追问、掌握度记录。
- 没有邀请码（内测期间注册需要邀请码）。
- 直接当教材使用：作品由 AI 和用户生成，科学性需要自己核。

## Skill

有官方 `SKILL.md`，以 zip 包从官网下载（2026-10-18 打包，v2.2.1），三个 Skill：

| Skill | 触发 / 用途 | 动作 |
|---|---|---|
| `dly-html` | 制作或改造自包含 HTML 互动作品（H5、互动课件、小游戏、Canvas/WebGL），做多端适配、静态审计、浏览器布局检查和本地预览；不上传 | 做课 |
| `dongleya-content-asset-skill` | 用户明确说「上传」时生成封面、上传为投稿临时副本，或为已发布作品准备候选版本；Agent 不替用户发布 | 做课（交付） |
| `dly-content-source` | 用个人 Agent Token 查询并下载本人线上草稿或已发布作品源码 | 备 |

个人令牌在官网 `/tokens` 页面创建，有效期 7–180 天，通过 MCP 的 `X-Agent-Token` 使用（Skill 原文）。产品内的创作 Agent 本身没有公开 Skill 文件。总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)，Skill 列表见 [skills/education-community.md](../../skills/education-community.md)。
