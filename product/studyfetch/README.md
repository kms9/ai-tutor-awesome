# StudyFetch

- 形态：商业 SaaS
- 链接：[官网](https://www.studyfetch.com)
- 状态：观察

## 简介

上传 PDF、PPT、视频或手写笔记，生成闪卡、测验、摘要；家教 Spark.E 基于你的课件回答，并有语音辅导和课堂转写。定位接近 Quizlet 的 AI 升级，主动规划弱于 Hyperknow。

## 建议使用场景

- 大学生把本周课件变成可刷的复习包。
- 需要语音讲题、直播课转写。
- 不适合：自托管、深度研究、视觉知识结构。
