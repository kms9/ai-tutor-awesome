## 简介

底座是白板、卡片、PDF/视频和双向链接。AI Tutor 根据学习目标商量大纲、按课时带读你空间里的源、课末用问题检查理解。AI Skills 是另一层：把「抽主张做思维导图并链回原文」做成可复用工作流。家教和笔记在同一张桌子上，不是外挂聊天框。

更细的能力拆解见 [../../capabilities/heptabase.md](../../capabilities/heptabase.md)。

## 建议使用场景

- 读一本难书、啃一个领域，需要主张之间的空间关系。
- 研究与学习不要分开：高亮、引用、续课都留在知识库。
- 想让 Claude Code 等外部 Agent 通过 CLI Skills 操作同一空间。
- 不适合：要 AI 同学举手讨论；要机构 LMS 分发；要完全开源自托管。
