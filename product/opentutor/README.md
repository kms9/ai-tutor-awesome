# OpenTutor

- 形态：开源自托管，本地优先
- 链接：[GitHub](https://github.com/zijinz456/OpenTutor)
- 状态：观察

## 简介

上传 PDF / DOCX / PPTX（可接 Canvas）后生成结构化笔记、闪卡、测验和自适应导师。强调 FSRS 间隔重复、知识图谱和认知负荷。体量小于 OpenMAIC / DeepTutor，形态接近「本地复习工作区」。

## 建议使用场景

- 资料不能出本机，又能接受自己配 Ollama 或 API Key。
- 只要笔记—练习—间隔重复，不要课堂角色扮演。
- 不适合：要完整多智能体课堂或商业级打磨。
