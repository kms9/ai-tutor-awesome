# 欧拉讲题

- 形态：网易有道数学讲题 App（iOS / iPadOS，Android Beta）
- 链接：[官网](https://miniboard.youdao.com/) · [App Store](https://apps.apple.com/cn/app/id6808209255)
- 状态：观察
- 注意：正式名称是「欧拉讲题」，不是「欧拉解题」
- 收录说明：单题粒度、仅数学。按 README 收录标准满足第 2 条（分步讲解、动态板书与图形）和第 3 条（分步讲解 + 追问 + 作业批改）；第 1 条弱，只吃题目照片和作业照片，不吃 PDF 或知识库。

## 简介

拍一道数学题，App 在白板上边写边讲：先提示思考方向，再分步展开推导，配语音、公式、辅助线和可拖动的 3D 图形，讲完归类所用方法、点明考察点。任一步没懂可以用语音或文字追问；另有「自己当老师」模式，让学生用自己的话讲一遍思路，AI 追问并纠正。作业批改支持拍整张试卷，查看批改结果后进入错题讲解。教学姿态接近 Khanmigo / Brilliant Koji 的「先引导、再讲解」，但单位是一道题，不是一门课。

## 建议使用场景

适合：

- 中小学生做数学题卡在某一步，要看推导过程和图形，而不只要答案。
- 几何辅助线、函数图像、立体图形这类需要「看见」的题目。
- 家长辅导数学作业：整卷拍照批改后逐题讲错题。
- 对照「讲题 Agent」的交互设计：先给方向、分步追问、学生复述。

不适合：

- 数学以外的学科。
- 把讲义 / 教材 / PDF 变成课，或按章节系统学习（去 OpenMAIC / DeepTutor / Hyperknow）。
- 跨题的学习规划、掌握度追踪（只有历史回顾，未见规划，未核）。
- 要可安装 `SKILL.md`、自托管或换模型。

## Skill

无公开 `SKILL.md`。流程锁在 App 内：

| 产品流程 | 动作 | 对应维度 |
|---|---|---|
| 拍题 → 先提示思路 → 分步讲解 → 归类方法 | 教 | 解题/出题 |
| 边讲边画：语音 + 公式 + 辅助线 + 3D 图形 | 教 | 视觉知识结构 |
| 某一步追问（语音 / 文字） | 教 | 解题/出题 |
| 自己当老师：学生复述思路，AI 追问 | 练 / 评 | 解题/出题 |
| 作业 / 整卷批改 → 错题讲解 | 评 | 解题/出题 |
| 历史题目与批改记录 | 练 | 长期记忆（弱） |

总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)。

## 能力对照

| 维度 | 本产品 |
|---|---|
| 资料摄入 | 弱：题目照片、作业 / 试卷照片；不吃 PDF 或知识库 |
| 一键成课 | —（单题讲解，不成课） |
| 直播课堂 | —（白板讲题是一对一回放式讲解，可插话追问） |
| 解题/出题 | 强：分步讲解、追问、错因分析、整卷批改；出题未见（未核） |
| 主动规划 | — |
| 长期记忆 | 弱：历史题目与批改记录 |
| 视觉知识结构 | 强（单题内）：动态板书、辅助线、函数图像、可拖动 3D 图形 |
| 可复用 Skill | 无 |
| 自托管 / 换模型 | 否 |
| 导出 | 未核 |

相对锚点：解题讲解的可视化强于四锚点里的 DeepTutor 文本解题，但没有 DeepTutor 的知识库和记忆；与 Khanmigo、Brilliant Koji 同属「不直接给答案」的导师姿态，区别是从学生自己拍的题出发、只做数学。
