# cn-math-taxonomy（中小学·高中知识图谱 + 自适应前置诊断）

- 形态：开源数据集 + 纯静态网站（知识图谱浏览、诊断工具），CC BY-NC 4.0
- 链接：[GitHub](https://github.com/xiaoyang111222/cn-math-taxonomy) · [在线站 math.pansgo.com](https://math.pansgo.com/) · [诊断演示（配方法）](https://math.pansgo.com/diagnose/?target=cnm_221&demo=1)
- 状态：观察

## 简介

按人教版等国内教材和课程标准整理的知识点先修图，附题库和一个自适应「前置诊断」页面。选一个目标知识点或整册，页面按先修边出题：答错先出一道确认题，确认题也错才判为薄弱，并沿先修边往回追（hard 先于 soft），数学可从高中一路追到小学具体知识点；最后给出薄弱根因、不稳知识点、按年级排的学习路径和相关课标条目。仓库名仍叫 math，现已扩到英语、物理、语文、科学、道德与法治、历史、地理、生物、化学。诊断引擎是规则算法，使用时不调用大模型；知识点、先修边和题目由 AI 生成，README 写明未经教师审核。

## 建议使用场景

适合：

- 学生或家长在某个知识点卡住时，找出前面学段里没打牢的先修点。
- 教研或产品团队拿一份中文先修图 + 课标映射做诊断、推荐或 Agent 的知识底座。
- 对照 Marble os-taxonomy 的 `topics` + `dependencies` 格式，做中文教材版本的映射。

不适合：

- 把自己的讲义 / PDF 变成课（不吃用户材料）。
- 要讲解、追问或 AI 家教（只出题和给路径，不讲）。
- 直接当作教学结论使用：先修强度、题目难度未经教师或学生数据校准（README 自述）。
- 商业产品直接使用（CC BY-NC 4.0，商用需另行授权）。

## Skill

无公开 `SKILL.md`。可复用的是数据文件和静态页面：

| 产品流程 | 动作 | 对应维度 |
|---|---|---|
| 知识点 + 先修边 + 课标映射（JSON） | 备 | 视觉知识结构 |
| 自适应前置诊断（确认题 → 回溯先修） | 评 | 解题/出题 |
| 按年级排序的学习路径 | 规划 | 主动规划（弱） |
| 本机盲区汇总、一键再测 | 练 | 长期记忆（弱，localStorage） |

总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)。

## 能力对照

| 维度 | 本产品 |
|---|---|
| 资料摄入 | —（内置教材知识点，不吃用户材料） |
| 一键成课 | — |
| 直播课堂 | — |
| 解题/出题 | 中：内置题库 + 自适应诊断，每个知识点最多问 2 题；不讲解 |
| 主动规划 | 弱：诊断后给按年级排序的学习路径 |
| 长期记忆 | 弱：诊断记录与盲区存在本机浏览器，不上传 |
| 视觉知识结构 | 强：先修图（Cytoscape 局部图）+ 课标映射 |
| 可复用 Skill | 无；数据为 JSON，可被其他 Agent 读取 |
| 自托管 / 换模型 | 是：纯静态站点，`python3 -m http.server` 即可；诊断不依赖模型 |
| 导出 | 诊断结果可导出 JSON、打印、生成分享图 |

相对锚点：先修图和回溯诊断是四锚点都没有的一层，适合给 DeepTutor / OpenMAIC 一类系统当知识底座；但它没有资料摄入、成课、讲解和对话。
