- 形态：Khan Academy 闭源家教
- 链接：[Khan Labs](https://www.khanacademy.org/khan-labs)

## 简介

绑在 Khan Academy 课程上的苏格拉底式家教。教学姿态成熟（追问、不直接代做），但不是资料进、整课出的通用 Agent，也不能自托管。

## 建议使用场景

- 对照「好老师该怎么问」，写自己的 tutor Skill。
- K12 / 早大学科、已在用 Khan 内容。
- 不适合：自有课件知识库、开源二次开发。
