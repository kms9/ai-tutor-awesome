# DeepTutor

- 形态：开源自托管 / CLI / Docker
- 团队：香港大学 HKUDS
- 链接：[GitHub](https://github.com/HKUDS/DeepTutor) · [站点](https://deeptutor.info)
- 状态：重点对照

## 简介

Agent 原生学习工作区。Chat、解题、出题、研究、可视化、掌握路径跑在同一套 Agent 循环上，共享知识库、笔记本和三层可审计记忆。支持多引擎 RAG、Partners 接到 IM、EduHub 教育 Skill。偏「长期学伴 + 研究台」，不是演一节课。

## 建议使用场景

- 教材、论文、代码仓库要进自己的库，并且答案要带出处。
- 需要同一条对话里切换「讲清楚 / 帮我解 / 出套题 / 做综述」。
- 要本地部署、换模型、把 TutorBot 接到飞书或 Telegram。
- 不适合：只想要精美课堂演出，或完全不想维护 Python/Node 环境。
