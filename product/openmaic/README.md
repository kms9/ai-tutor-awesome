- 状态：重点对照

## 简介

Open Multi-Agent Interactive Classroom。输入主题或上传资料，几分钟内生成一节完整互动课：幻灯片、测验、HTML 模拟、项目式学习，并由 AI 教师和 AI 同学讲解、讨论、在白板上写画。v1.0 增加 Pro workbench，可用对话规划并改课。可导出 PPTX / HTML，可接多种 LLM（含本地 Ollama）。

## 建议使用场景

- 教研或教师：已有 PPT，想补讲解、提问和互动，而不是再做一套录播。
- 自学者：希望「上课」而不是对着文档聊天。
- 产品对照：要看多智能体课堂运行时（角色、白板、语音、场景类型）。
- 不适合：只要闪卡刷题、或必须完全离线且不想跑 Node 服务。
