## 简介

主动式学习 Agent（产品中常称 Orbie）。上传课件与大纲后，不只等你提问，还会抽截止日期、排计划、生成 cheatsheet、闪卡、练习和短讲解视频。强调长文档精读与页级引用，可接 Canvas 一类 LMS。

## 建议使用场景

- 学期中或多门课并行，需要有人先读材料再准备复习包。
- 备考：一页纸 cheatsheet、练习题、两分钟概念视频。
- 接受订阅、材料可以上云。
- 不适合：必须自托管；或主要诉求是多智能体课堂表演。
