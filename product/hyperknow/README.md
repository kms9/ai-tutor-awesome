## 简介

主动式学习 Agent（产品中常称 Orbie）。上传课件与大纲后抽取截止日期、排计划、生成 cheatsheet、闪卡、练习和讲解视频。强调最长约 1000 页精读与页级引用，可接 Canvas。没有公开的 Agent Skills 仓库，流程都锁在产品里。它解决的是「学期中有人先读材料再准备复习包」，不是课堂演出，也不是可审计记忆工作区。

## 建议使用场景

适合：

- 学期中或多门课并行，需要有人先读材料再准备复习包。
- 备考：一页纸 cheatsheet、练习、短概念视频。
- 学校在用 Canvas，接受订阅、材料可以上云。

不适合：

- 必须自托管或换模型。
- 主要诉求是多智能体课堂。
- 要可复用 `SKILL.md` 二开，或把 Orbie 装进 Claude Code。
- 深度主题研究要主张图 / 页级卡片桌面（去 Heptabase）。

## Skill

无公开 Agent Skills 仓。把产品按钮当成锁死 Skill 来对照：

| 产品流程 | 动作 | 对应维度 |
|---|---|---|
| 大纲/Canvas → 抽截止日期 | 规划 | 主动规划 |
| Deep Learn 会话 | 教 | 一键成课 |
| cheatsheet / 闪卡 / 练习 | 练 | 解题/出题 |
| 讲解视频 | 做课 | 视觉（视频，不是白板） |
| Learner Persona / Memory | 记忆 | 长期记忆（不可审计程度未核） |

不能安装、不能 fork、不能改触发条件。总表见 [capabilities/skill-map.md](../../capabilities/skill-map.md)。

## 能力对照

| 维度 | 本产品 |
|---|---|
| 资料摄入 | 强：课件/大纲/约 1000 页 + Canvas |
| 一键成课 | 强：1:1 Deep Learn，不是课堂场景 |
| 直播课堂 | 弱 |
| 解题/出题 | 强：练习与讲解，非竞赛级深解题 |
| 主动规划 | 极强：Orbie 未问先准备 |
| 长期记忆 | 中：学习风格 / Memory 档，不可打开成图 |
| 视觉知识结构 | 中：讲解视频，无主张图 |
| 可复用 Skill | 无公开文件 |
| 自托管 / 换模型 | 否 |
| 导出 | cheatsheet / 视频；打印可用性未核 |

相对锚点：主动规划与备考资产最强；演课、开源 Skill、视觉知识库都不是它的战场。
