## 简介

主动式学习 Agent（产品中常称 Orbie）。上传课件与大纲后抽取截止日期、排计划、生成 cheatsheet、闪卡、练习和讲解视频。强调最长约 1000 页精读与页级引用，可接 Canvas。没有公开的 Agent Skills 仓库，流程都在产品内。

## 建议使用场景

- 学期中或多门课并行，需要有人先读材料再准备复习包。
- 备考：一页纸 cheatsheet、练习、短概念视频。
- 接受订阅、材料可以上云。
- 不适合：必须自托管；主要诉求是多智能体课堂；要可复用 `SKILL.md` 二开。
