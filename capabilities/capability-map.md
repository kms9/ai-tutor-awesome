# 能力图谱

用同一组维度打产品，避免「都叫 AI Tutor」却不可比。

| 维度 | 含义 | OpenMAIC | DeepTutor | Hyperknow | Heptabase |
|---|---|---|---|---|---|
| 资料摄入 | PDF/PPT/视频/LMS | 强 | 强（多引擎 RAG） | 强（约 1000 页）+ Canvas | 强（PDF/YT/Zotero/Readwise） |
| 一键成课 | 大纲+场景生成 | 极强（课堂场景） | 中（Book/Mastery） | 强（1:1 课） | 强（目标→课程） |
| 直播课堂 | 老师/同学/白板/语音 | 极强 | 弱 | 弱 | 弱（白板是思考桌不是讲台） |
| 解题/出题 | 多步推理、仿考试 | 有测验 | 极强 | 强 | 课末提问，题库弱 |
| 主动规划 | 未问先准备 | 弱 | Partners 可主动 | 极强（Orbie） | 中（续课，非抢日程） |
| 长期记忆 | 跨会话可审计 | 会话级 | 三层 Memory | 学习风格记忆 | 空间即记忆 |
| 视觉知识结构 | 卡片/白板/主张图 | 课堂白板 | 可视化模式 | 讲解视频 | 极强 |
| 可复用 Skill | Agent playbook | 自带 openmaic skill | EduHub + SKILL.md | 产品内流程 | App Skills + CLI Skills |
| 自托管 / 换模型 | | 是 | 是 | 否 | 否（可 BYOK 部分） |
| 导出 | PPTX/HTML 等 | 强 | MD/笔记本 | cheatsheet/视频 | 空间内为主 |

新增产品时只加列，不改行名，除非开 Issue 讨论维度本身。
