# 学习方法、写作技巧与提示词

巡查：2026-11-06。收与「用 AI 学习 / 教学 / 理解输出」相关的方法、写作技巧、单条提示词和非教学向 Skill 合集。它们不是产品，也不是「教人 / 做课」的 Skill，所以不进产品索引和 [skills/](../skills/)。

只写方法本身：步骤、约束、适用场景、原文给出的提示词结构。原文里的情绪化推荐和营销话术不搬过来。

## 收录规则

1. 能直接照做：有步骤、规则或可复制的提示词结构；纯感想不收。
2. 与学习、教学、理解或写作有关；与教育无关的 Skill 合集只在「相邻 Skill 合集」里收，并写明「非教学向」。
3. 已是可安装的教学 Skill（`SKILL.md` + 教 / 练 / 做课）的，进 [skills/education-community.md](../skills/education-community.md)，这里不重复。
4. 提示词写结构和关键约束，不整段转载长提示词；需要原文时链原始出处。
5. 来源优先链原帖 / 原文 / 仓库；找不到原始出处时链得到笔记，并标「原始出处未核」。
6. 同一技巧多条笔记合并成一条，补充说法写明是谁补充的。
7. 每个小节内按日期倒序（新的在上）。

### 问题驱动学习（PBL）+ AI 陪练

- 类型：学习方法
- 日期：2026-07-05
- 来源：[Yangyi 即刻原帖](https://m.okjike.com/originalPosts/6a49ecac54aae0885e73c775) · [得到笔记](https://www.biji.com/note/1914738385609122656)

- 适用场景：从零进入一个新领域

- 把框架交给 AI，让 AI 当陪练。

- 适用场景：讲课、学术报告、求职演讲

- 约一小时，覆盖开场、内容设计、板书 / 道具 / 幻灯片等工具使用、求职演讲、收尾。

## 用 AI 理解与写作

### Karpathy：理解 LLM 输出的四种格式（ASD-STE100 → 图 → HTML → 视频）

- 类型：提示词
- 日期：2026-10-02
- 来源：[Karpathy 原帖](https://x.com/karpathy/status/2105819303471976479) · [得到笔记](https://www.biji.com/note/1923143880346338448)
- 核查：已核原文（经原帖全文转录核对）
- 适用场景：读懂模型输出、讲解概念、给学生做解释材料

- 文字：让模型用 ASD-STE100 讲解。ASD-STE100 是为航空航天维护文档制定的受控语言规范，约束严格时可要求「80% 接近 ASD-STE100」。
- 图：让模型画图表代替文字。
- 网页：要求输出「in HTML」，得到可交互网页。
- 视频：生成定制讲解视频，例：「Create a 3b1b style video explainer on X」，旁白用 TTS API 或本地免费替代。

### 禁止 AI 使用副词（中文：禁用装饰性状语、补语）

- 类型：写作技巧
- 日期：2026-09-01
- 来源：[沐阳 @yyyole 原帖](https://x.com/yyyole/status/2094711459704098991) · [得到笔记 1](https://www.biji.com/note/1920380610058393888) · [得到笔记 2](https://www.biji.com/note/1920380621871126816)
- 核查：原帖已核；AI磊叔补充为转述（未核）
- 适用场景：让 AI 写叙述、讲解、文案时减少空泛修饰

- 做法：在写作指令里禁止 AI 使用副词。原帖称这样写出的内容更有画面感。
- AI磊叔（@AgiRay1015）补充：「副词」是英语语法概念，中文对应的做法是禁止无意义、装饰性的状语和补语。
- 两条笔记合并；第二条记录了上述语法用词的讨论。

## 提示词

### 双向钢人论证 Prompt

- 类型：提示词
- 日期：原文日期未核；笔记 2026-08-18
- 来源：[卡兹克原文（虎嗅转载）](https://www.huxiu.com/article/4883808.html) · [得到笔记](https://www.biji.com/note/1918792221630066568)
- 核查：已核原文
- 适用场景：做决策、检验自己的观点、减少模型顺着用户说

结构四步：

1. 用最完整、有力的方式重述用户真正想解决的问题。
2. 用钢人论证分别给出支持和反对用户当前想法的最强论证。
3. 找出双方真正的分歧和最可能改变结论的关键变量。
4. 只问用户一个最关键的问题；用户回答后再给明确判断、理由和下一步行动。

另有社区 Skill 化版本：[LearnPrompt/laoyeye `steelman-both-sides`](https://github.com/LearnPrompt/laoyeye/blob/main/skills/deciding/steelman-both-sides/SKILL.md)。

### 康奈尔笔记信息图提示词（GPT-Image）

- 类型：提示词
- 日期：2026-07-26
- 来源：[知识分享官 @knowledgefxg 原帖](https://x.com/knowledgefxg/status/2081354526003712415)
- 核查：已核原文（经公开镜像读取原帖全文核对）
- 适用场景：把一个主题整理成一页可打印的复习笔记；给学生做单元总结页

- 用法：把提示词中的【主题】换成要学的内容，交给图像模型生成一张信息图；原帖称用于 GPT-Image，附 4 张示例图。
- 版式按康奈尔笔记分区：顶部写标题、日期、科目、课题；左侧约 25% 宽为线索栏，放 8–12 个编号问题；右侧约 75% 宽为笔记栏，按知识点分模块，每个模块含小标题、简洁解释、项目符号、流程图、箭头关系、表格、示意图和图标，要求图文结合；底部总结栏用 2–5 句话回顾；右下角加「一句话记忆」。
- 风格约束：A4 竖版、扁平化、白色背景、马卡龙配色（蓝、绿、橙）、大量留白、圆角边框、浅色分区、字号分层、图标风格统一，适合打印和电子阅读。
- 内容要求：围绕主题整理，准确、层次清晰、重点突出、便于复习。
